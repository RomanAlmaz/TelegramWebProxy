О проекте

Живые спотовые курсы без лишнего шума

CoinTrack - лёгкая рыночная доска для быстрого взгляда на основные активы в USD и RUB. В фокусе фиксированный набор ликвидных монет, короткие графики и понятное изменение за сутки - без ленты новостей и кнопок торговли.

Интерфейс сделан как спокойная рабочая панель: достаточно плотный для ежедневной проверки и достаточно пустой, чтобы считать его за несколько секунд. Котировки обновляются из публичных API в браузере; ордера и хранение средств здесь не выполняются.

Для кого

Для тех, кто уже знает свой список активов и хочет только снимок рынка: открыл, посмотрел, закрыл. Если нужны плечо, стейкинг или синхронизация портфеля - это сознательно другой продукт.
